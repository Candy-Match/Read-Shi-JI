# 读史记 · 在线《史记》阅读器

仿「读通鉴」的产品框架，用《史记》全文重建的在线阅读站：可对照、可追踪、可推演。

**在线访问**：https://candy-match.github.io/Read-Shi-JI/

## 有什么

- **阅读**：130 篇全文、3,505 段、逐段文白对照、4,700+ 条注释、生僻字注音、宋/楷/黑三体、日间/护眼/夜间、目录树、段落深链、全文检索。
- **知识**：点正文人名/地名/词条直接出面板——181 人小传与 522 条关系、160 处古地名、100 条百科词条；「出现段落聚合」把散见各篇的记载汇总，编年史读出纪传感。
- **空间**：示意古地图（图层可开关、战国疆域推演）、10 场战役沙盘（44 阶段、74 条路线、自动推演）、秦汉官制分层图。
- **解读**：纪事本末 40 个事件专题、40 首咏史诗、79 条历代名家伴读评点、五千年气候曲线。
- **互动**：四色划线批注、收藏/书签/进度/足迹、16 张决策卡（选项·投票·史实）、史记助手（本地检索式问答）。

## 技术

Vue 3 + 手写 CSS，Rollup 打包为纯静态站点（280 KB JS + JSON 数据），Hash 路由 + 相对路径，可直接部署在任意静态托管或子目录。

## 目录

```
index.html            入口
assets/               构建产物（app.js / style.css）
data/                 130 篇结构化数据 + 人物/地名/战役/事件/诗词/决策/词条/气候/伴读
```

## 说明

- 原文、白话译文、注释、导读、解读来自开源整理本（GitHub: `biechuyangwang/jingdian`）；人物、地名、战役、事件、诗词、决策、词条、官制、气候、伴读为本项目整理撰写。
- 地图与沙盘为**示意性还原**：坐标取今地，路线据史文与通行史地考证推演，非考古测绘。
- 批注/收藏等个人数据保存在浏览器本地（localStorage），不跨设备同步。
- 研究性演示项目，非商业站点。
