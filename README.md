# 读史记 · 在线《史记》阅读器

仿「读通鉴」（dutongjian.com）的产品框架，用《史记》全文重建的一个在线阅读站。
目标不是做一个电子书，而是把编年/纪传体的文本拆成**可对照、可追踪、可推演**的多层阅读空间。

> **在线访问**：<https://candy-match.github.io/Read-Shi-JI/> ｜ <https://read-shi-ji.netlify.app/>
>
> 本地运行：<http://127.0.0.1:5188/>（
ode server.mjs）
> 构建产物在 `dist/`，服务脚本为 `server.mjs`（零依赖静态服务器）。

---

## 一、功能一览

### 阅读器（基础，全部可用）
- **文白对照**：左右分屏逐段对照，可切「对照 / 仅原文 / 仅译文」；窄屏自动上下排。
- **注释**：每篇附注释（篇末完整列表 + 正文角标 + 点击弹出气泡），共 4,700+ 条。
- **生僻字注音**：原文自带拼音，一键开关，以 ruby 注在上方。
- **排版**：宋体/楷体/黑体、字号、行距、日间/护眼/夜间三模式。
- **目录树**：本纪 12 / 表 10 / 书 8 / 世家 30 / 列传 70，共 130 篇，可筛选、显示进度。
- **段落深链**：`#/c/7/18` 直达第 7 篇第 18 段，可一键复制。
- **全文检索**：原文 + 译文 3,505 段可检索，结果高亮并定位到段。

### 知识层
- **人物面板**（正文点人名 / 人物志）：小传、别名、生卒、关系图谱（亲属/君臣/对手/同盟…）、相关篇目、**出现段落聚合**（把散见各篇的记载汇总，编年史读出纪传感）。181 人、522 条关系。
- **地名面板**：160 处古地名，今地对照、类型、史事、相关篇目。
- **通鉴百科**：100 条官职、制度、礼乐、军事、经济、法律、典故词条，正文中金色虚线高亮。

### 空间层
- **历史地图**：示意古地图（计里画方 + 水系 + 陆界 + 160 地名），图层可开关，战国七雄疆域示意（由城邑点集推演），点地名出详情。
- **沙盘态势**：10 场战役（阪泉、涿鹿、牧野、桂陵、马陵、长平、巨鹿、井陉、垓下、白登），分阶段推演行军路线、交战点，支持「自动推演」，地图自动聚焦战场范围。
- **历代官职**：秦汉三公九卿官制分层图（31 个节点）。

### 解读层
- **纪事本末**：40 个事件专题，按「事」重组散落各篇的记载。
- **后人咏史**：40 首历代咏《史记》人物事件的诗词，关联篇目。
- **伴读**：79 条历代名家评点（凌稚隆、茅坤、金圣叹、泷川资言…），按篇聚合。
- **历史气候**：竺可桢五千年气温曲线示意（44 点、10 个冷暖分期），叠加朝代刻度，鼠标可读数。

### 互动层
- **批注**：选中原文 → 四色划线 + 文字批注，可点开查看/删除。
- **收藏 / 书签 / 阅读进度 / 足迹**：本地保存。
- **决策演武场**：16 张历史抉择卡——局面、两个选项的支持/反对理由、投票比例、史实选择与结果。
- **史记助手**：右栏 AI 面板，本地检索式问答（给出相关记载与出处），附应用宫格。

### 账号与其它
- 本地登录（昵称即可）、个人空间（批注/收藏/书签/足迹/进度/投票）。
- 演示性「会员」标记、PWA manifest、移动端适配。

## 三、技术实现

```
src/
  main.js              入口
  App.vue              布局、Hash 路由、全局弹层
  store.js             全局状态（设置/用户/批注/进度）+ 数据加载
  lib/render.js        正文渲染：注音、实体高亮、注释角标、批注区间
  lib/md.js            篇末「解读/拓展」的轻量 Markdown 渲染
  lib/geo.js           经纬度投影、示意底图、凸包疆域
  components/          TopBar / TocPane / Assistant / MapCanvas / SettingsModal / DialogueHost
  views/               Reader / Events / People / Map / Sandbox / Poems / Decisions /
                       Lexicon / Climate / Offices / Me / Search / About
tools/
  parse.mjs            解析底本 Markdown → data/chapters/*.json
  sync-data.mjs        汇总目录、搜索索引、实体词表 → public/data
  build.mjs            Rollup 打包 + 静态资源复制 → dist/
data/
  chapters/            130 篇结构化数据
  enrich/              人物、地名、战役、事件、诗词、决策、词条、官制、气候、伴读
data_raw/
  jingdian/            底本 Markdown（130 篇，含原文、译文、注释、导读、解读）
server.mjs             零依赖静态服务器
```

- 前端：**Vue 3**（`vue.runtime.esm-browser.prod`）+ 手写 CSS，无 UI 框架，视觉对齐原站的米色纸张 / 宋体 / 蓝色 chips 体系。
- 构建：**Rollup**（纯 JS，不依赖 esbuild 子进程），产物 280KB。
- 数据：静态 JSON，按篇懒加载；搜索索引与实体词表在同步阶段预生成。

### 重新构建

```bash
# 1. 解析底本（首次或底本变更后）
node tools/parse.mjs
# 2. 同步数据到 public/ 并生成索引
node tools/sync-data.mjs
# 3. 打包
node tools/build.mjs
# 4. 启动
node server.mjs        # http://127.0.0.1:5188
```

## 四、底本与说明

- 原文、白话译文、注释、导读、解读均来自开源整理本《经典著作解读·史记》（GitHub: `biechuyangwang/jingdian`），已按其体例解析；属公有领域原文 + 该项目自撰译注。
- 人物、地名、战役、事件、诗词、决策、词条、官制、气候、伴读等结构化内容为本项目自行整理撰写；气候曲线据竺可桢研究趋势示意，非逐点测量值。
- 地图为**示意古地图**：坐标取今地，路线据史文与通行史地考证推演，非考古测绘。
- 未实现（相对原站）：繁体竖排切换、三家注逐条嵌入、古本影印对照。
- 本站为研究性演示项目，非商业站点。
