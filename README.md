# 读史记 · 在线《史记》阅读器

仿「读通鉴」的产品框架，用《史记》全文重建的在线阅读站：可对照、可追踪、可推演。

**在线访问**
- GitHub Pages：<https://candy-match.github.io/Read-Shi-JI/>
- Netlify：<https://read-shi-ji.netlify.app/>
- 本地：`node server.mjs` → <http://127.0.0.1:5188/>

---

## 功能（v1.2）

### 阅读
- 130 篇全文、3,505 段、约 62 万字；逐段**文白对照**（对照／仅原文／仅译文）
- **注释** 4,700+ 条（篇末列表＋正文角标＋气泡）、**生僻字注音**可开关
- 宋／楷／黑三体、字号、行距、日间／护眼／夜间；目录树、段落深链、全文检索

### 年表（v1.1 新增）
- **十表数据化**：三代世表（世系树）、十二诸侯年表（120 行）、六国年表（256 行，前476—前221）、秦楚之际月表（42 行）、汉兴以来诸侯王年表（48 条）、四张侯者年表（135 条）、将相名臣年表（94 行）
- 表格可检索、可隐藏无记载年份、纪年可直达纪传

### 资料库 · 《汉书》（v1.1 新增）
- 收录与《史记》重叠的 **40 篇**《汉书》纪传（约 29 万字，原文＋白话）
- 按人物、地名共现生成 **3,045 条段级对照**：读到汉初纪传，可直接展开《汉书》相应段落

### 知识层
- **人物志**：181 人小传、522 条关系、出现段落聚合（编年读出纪传感）
- **历史地图**：160 处古地名、四种疆域（战国七雄／秦／楚汉分封／汉初）、水系／山脉／计里画方图层、滚轮缩放＋拖拽平移＋鹰眼、现代地名切换
- **沙盘态势**：10 场战役、44 阶段、74 条路线，阶段时间轴、自动推演、地图字幕；**地名面板内嵌战役沙盘缩略图**，正文相关段落可直接点「沙盘 · 巨鹿」进入
- **通鉴百科** 100 条；**历代官职** 31 节点分层图

### 解读与互动
- 纪事本末 40 个事件专题、咏史诗 40 首、伴读评点 79 条、五千年气候曲线
- **批注**（v1.2 升级）：正文划线处直接出现「✎」小标与「✎ 批注 n」段落入口，**点一下就弹出该段批注并可就地编辑**；侧栏汇总（本篇／全部）、点句定位、导出／导入 JSON、多标签页实时同步
- 收藏／书签／进度／足迹、决策演武场 16 张卡

### 账号与 AI（v1.1 新增）
- **本地账号**：注册／登录，数据按账号隔离，可导出全量数据迁移
- **史记助手**：可配置任意 OpenAI 兼容接口（如 DeepSeek），检索《史记》段落作为上下文并流式作答；Key 仅存本机。未配置时回退本地检索模式

## 技术

- 前端：Vue 3 + 手写 CSS，Rollup 打包为纯静态站点（约 350 KB JS + JSON 数据）
- 数据：静态 JSON，按需加载；构建期生成搜索索引、实体词表与《汉书》对照索引
- 部署：GitHub Pages（`main` 根目录）与 Netlify（zip 部署）双线

```
tools/
  parse.mjs              底本 Markdown → 章节 JSON
  fetch-hanshu.mjs       下载并解析《汉书》40 篇
  build-hanshu-links.mjs 生成史汉段级对照索引
  sync-data.mjs          汇总数据、合并十表、生成索引
  build.mjs              Rollup 打包
  push-github.mjs        经 Git Data API 推送（无需 git）
  deploy-netlify.mjs     Netlify API 部署
```

- 批注等数据保存在浏览器本地（按账号隔离），不跨设备同步；请用「个人空间 → 导出数据」迁移。
